# Petpheus

This is a basic slack bot which makes a pet GIF out of people's profile pictures, any image you provide or any existing emojis and adds them in the workspace as a custom emoji.

---

## what it does

- pet a user - ping the user you want to pet, then include the name of the emoji
- pet an image - upload an image, then include the name of the emoji
- pet an emoji - use an existing emoji and then include the name of the new emoji

**MAKE SURE TO THANK HIM**

---

## usage

### pet a user's pfp
```
@username emoji-name
```
example: `@user123 pet-user123`

### pet an uploaded image
upload an image and type the emoji name as the message caption.

### pet an existing emoji
```
:emoji-name: new-name
```
example: `:sob: pet-sob`
